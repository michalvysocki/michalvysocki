## Selected Projects

### Anchor
Research project on world models and long-horizon prediction in latent representation spaces.

Investigating horizon-conditioned predictive models, stable latent rollouts, representation quality, and methods for reducing long-term prediction drift.

### Drone Audio Detection
Machine learning system for detecting UAVs from acoustic signals.

Covers the full experimental pipeline: audio preprocessing, augmentation, grouped validation, deep learning models, experiment tracking, reproducibility, and live inference.

### DOC

Built around document processing, semantic retrieval, embeddings, and LLM-based workflows for understanding complex material and organizing research knowledge.
